此skill講述代碼審查的基本方法、不專限定某一特定編程語言。

## 功能正確性

這是最首要的一步。 檢查代碼功能邏輯是否正確、是否有Bug

## 覈對需求

審查代碼實現是否符合需求

## 性能

看代碼是否有性能問題。 需考慮時間複雜度和空間複雜度。 常出現的問題有:

- 使用了不合適的數據結構導致時間複雜度/空間複雜度非最優
- 在線性列表中頻繁查找而非使用字典
- 可能導致把大量數據一次性全加載進內存而未採用流式處理/迭代器

## 工程設計

- 是否符合工程設計規範、是否有可維護性、可擴展性問題。
- 模塊設計是否高內聚低耦合。
- 是否反模式 是否遵守基本的設計原則

## 代碼規範

- 是否符合規定的代碼規範(不同語言 不同項目可能有不同的規範、以實際規範爲準。可自行查找有無相關skill)
- 代碼可讀性
- 註釋
