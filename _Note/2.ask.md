**1. `JsonTypeInfo<T>`**

`JsonTypeInfo<T>` 提供关于类型的 JSON 序列化相关元数据 [1](https://learn.microsoft.com/en-us/dotnet/api/system.text.json.serialization.metadata.jsontypeinfo?view=net-9.0)。你可以用它来定制序列化和反序列化的过程，例如指定自定义转换器、命名策略等。

*   **主要用途**：

    *   **AOT 编译优化**：在 AOT (Ahead-of-Time) 编译场景下，`JsonTypeInfo<T>` 可以预先生成序列化元数据，避免运行时的反射开销 [2](https://stackoverflow.com/questions/78639150/use-system-text-json-converters-with-jsontypeinfo-for-aot)。
    *   **自定义序列化**：允许你完全控制类型的序列化方式，例如使用自定义的 `JsonConverter`。
    *   **元数据访问**：提供对类型序列化信息的访问，例如属性列表、转换器等。
*   **如何使用**：

    1.  **创建 `JsonSerializerOptions`**：首先，你需要创建一个 `JsonSerializerOptions` 实例，并配置你需要的选项。
    2.  **获取 `JsonTypeInfo<T>`**：通过 `JsonSerializerOptions.GetTypeInfo(Type type)` 方法获取 `JsonTypeInfo<T>` 实例。
    3.  **自定义元数据**：修改 `JsonTypeInfo<T>` 的属性，例如 `Converter`、`NumberHandling`、`PropertyNamingPolicy` 等。
    4.  **序列化/反序列化**：在 `JsonSerializer.Serialize` 和 `JsonSerializer.Deserialize` 方法中使用 `JsonSerializerOptions`。

    ```csharp
    using System.Text.Json;
    using System.Text.Json.Serialization.Metadata;

    public class Example
    {
        public static void Main(string[] args)
        {
            // 1. 创建 JsonSerializerOptions
            var options = new JsonSerializerOptions();

            // 2. 获取 JsonTypeInfo<T>
            JsonTypeInfo<MyClass> typeInfo = (JsonTypeInfo<MyClass>)options.GetTypeInfo(typeof(MyClass));

            // 3. 自定义元数据 (例如，添加一个自定义转换器)
            // typeInfo.Converter = new MyCustomConverter();

            // 4. 序列化/反序列化
            var obj = new MyClass { Value = 42 };
            string json = JsonSerializer.Serialize(obj, options);
            Console.WriteLine(json);

            MyClass deserializedObj = JsonSerializer.Deserialize<MyClass>(json, options);
            Console.WriteLine(deserializedObj.Value);
        }
    }

    public class MyClass
    {
        public int Value { get; set; }
    }
    ```

**2. `JsonDocument`**

`JsonDocument` 表示一个 JSON 文档，提供对 JSON 数据的结构化访问。它被设计为只读的，并且在整个生命周期内都有效。

*   **主要用途**：

    *   **高性能读取**：提供比 `JObject` 等传统 JSON 库更高的性能，尤其是在大型 JSON 文档上。
    *   **结构化访问**：允许你通过属性和索引器访问 JSON 元素。
    *   **延迟解析**：只有在你访问特定部分时，才会解析 JSON 文档的相应部分。
*   **如何使用**：

    1.  **解析 JSON**：使用 `JsonDocument.Parse` 或 `JsonDocument.ParseAsync` 方法从字符串、流或字节数组中解析 JSON。
    2.  **访问根元素**：通过 `RootElement` 属性获取根 `JsonElement`。
    3.  **遍历和访问元素**：使用 `JsonElement` 的方法（如 `GetProperty`、`EnumerateArray`、`GetString`、`GetInt32` 等）来遍历和访问 JSON 数据。
    4.  **释放资源**：`JsonDocument` 实现了 `IDisposable` 接口，所以在使用完毕后需要释放资源。

    ```csharp
    using System.Text.Json;

    public class Example
    {
        public static void Main(string[] args)
        {
            string jsonString = @"{
                ""name"": ""John Doe"",
                ""age"": 30,
                ""address"": {
                    ""street"": ""123 Main St"",
                    ""city"": ""Anytown""
                },
                ""hobbies"": [""reading"", ""hiking"", ""coding""]
            }";

            using (JsonDocument document = JsonDocument.Parse(jsonString))
            {
                JsonElement root = document.RootElement;

                // 访问属性
                string name = root.GetProperty("name").GetString();
                int age = root.GetProperty("age").GetInt32();

                // 访问嵌套对象
                JsonElement address = root.GetProperty("address");
                string street = address.GetProperty("street").GetString();
                string city = address.GetProperty("city").GetString();

                // 遍历数组
                JsonElement hobbies = root.GetProperty("hobbies");
                Console.WriteLine("Hobbies:");
                foreach (JsonElement hobby in hobbies.EnumerateArray())
                {
                    Console.WriteLine($"- {hobby.GetString()}");
                }

                Console.WriteLine($"Name: {name}, Age: {age}");
                Console.WriteLine($"Address: {street}, {city}");
            }
        }
    }
    ```

**3. `JsonElement`**

`JsonElement` 表示 JSON 文档中的一个元素，可以是对象、数组、字符串、数字、布尔值或 null。它是 `JsonDocument` 的组成部分，用于访问 JSON 数据。

*   **主要用途**：

    *   **访问 JSON 数据**：提供各种方法来获取 JSON 元素的类型和值。
    *   **遍历 JSON 结构**：允许你遍历 JSON 对象和数组。
    *   **延迟读取**：只有在你需要时才读取 JSON 元素的值。
*   **如何使用**：

    1.  **从 `JsonDocument` 获取**：通过 `JsonDocument.RootElement` 或 `JsonElement.GetProperty` 等方法获取 `JsonElement` 实例。
    2.  **检查类型**：使用 `ValueKind` 属性确定元素的类型（`Object`、`Array`、`String`、`Number`、`True`、`False`、`Null`）。
    3.  **获取值**：使用 `GetString`、`GetInt32`、`GetBoolean` 等方法获取元素的值。
    4.  **遍历**：如果元素是对象，使用 `EnumerateObject` 方法遍历属性；如果元素是数组，使用 `EnumerateArray` 方法遍历元素。

    ```csharp
    using System.Text.Json;

    public class Example
    {
        public static void Main(string[] args)
        {
            string jsonString = @"{
                ""name"": ""John Doe"",
                ""age"": 30,
                ""isStudent"": false,
                ""grades"": [90, 85, 95]
            }";

            using (JsonDocument document = JsonDocument.Parse(jsonString))
            {
                JsonElement root = document.RootElement;

                // 检查类型并获取值
                if (root.TryGetProperty("name", out JsonElement nameElement) && nameElement.ValueKind == JsonValueKind.String)
                {
                    string name = nameElement.GetString();
                    Console.WriteLine($"Name: {name}");
                }

                if (root.TryGetProperty("age", out JsonElement ageElement) && ageElement.ValueKind == JsonValueKind.Number)
                {
                    int age = ageElement.GetInt32();
                    Console.WriteLine($"Age: {age}");
                }

                if (root.TryGetProperty("isStudent", out JsonElement isStudentElement) && isStudentElement.ValueKind == JsonValueKind.False)
                {
                    bool isStudent = isStudentElement.GetBoolean();
                    Console.WriteLine($"Is Student: {isStudent}");
                }

                if (root.TryGetProperty("grades", out JsonElement gradesElement) && gradesElement.ValueKind == JsonValueKind.Array)
                {
                    Console.WriteLine("Grades:");
                    foreach (JsonElement gradeElement in gradesElement.EnumerateArray())
                    {
                        if (gradeElement.ValueKind == JsonValueKind.Number)
                        {
                            int grade = gradeElement.GetInt32();
                            Console.WriteLine($"- {grade}");
                        }
                    }
                }
            }
        }
    }
    ```

**总结**

*   `JsonTypeInfo<T>` 用于自定义序列化元数据，主要用于 AOT 编译和高级定制。
*   `JsonDocument` 用于解析 JSON 文档，提供高性能的只读访问。
*   `JsonElement` 用于访问 `JsonDocument` 中的 JSON 元素，提供类型检查和值获取的方法。

    ```csharp
    using System;
    using System.Collections.Generic;
    using System.Linq;
    using System.Text;

    namespace SourceGenerator
    {
        [Generator]
        public class DictGenerator : ISourceGenerator
        {
            public void Execute(GeneratorExecutionContext context)
            {
                // 获取所有带有 DictTypeAttribute 特性的类
                var dictContextClasses = context.Compilation.SyntaxTrees
                    .SelectMany(syntaxTree => syntaxTree.GetRoot().DescendantNodes())
                    .OfType<ClassDeclarationSyntax>()
                    .Where(cds => cds.AttributeLists
                        .SelectMany(al => al.Attributes)
                        .Any(attr => attr.Name.ToString() == "DictType"))
                    .ToList();

                {
                    // 获取类名和命名空间
                    var className = classDeclaration.Identifier.Text;
                    var namespaceName = GetNamespace(classDeclaration);

                    // 获取 DictTypeAttribute 的 TargetType

                    if (targetType != null)
                    {
                        // 生成扩展方法
                        var sourceCode = GenerateExtensionMethod(namespaceName, className, targetType, context);
                        context.AddSource($"{className}Extensions.g.cs", sourceCode);
                    }
                }

            private string GetNamespace(ClassDeclarationSyntax classDeclaration)
            {
                SyntaxNode? potentialNamespaceParent = classDeclaration.Parent;
                while (potentialNamespaceParent != null &&
                       !(potentialNamespaceParent is NamespaceDeclarationSyntax) &&
                       !(potentialNamespaceParent is FileScopedNamespaceDeclarationSyntax))
                {
                    potentialNamespaceParent = potentialNamespaceParent.Parent;
                }

                if (potentialNamespaceParent is NamespaceDeclarationSyntax namespaceDeclaration)
                {
                    return namespaceDeclaration.Name.ToString();
                }
                else if (potentialNamespaceParent is FileScopedNamespaceDeclarationSyntax fileScopedNamespaceDeclaration)
                {
                    return fileScopedNamespaceDeclaration.Name.ToString();
                }

                return string.Empty;
            }

            private ITypeSymbol? GetTargetType(ClassDeclarationSyntax classDeclaration, GeneratorExecutionContext context)
            {
                foreach (var attributeList in classDeclaration.AttributeLists)
                {
                    foreach (var attribute in attributeList.Attributes)
                    {
                        if (attribute.Name.ToString() == "DictType" && attribute.ArgumentList != null && attribute.ArgumentList.Arguments.Count > 0)
                        {
                            var typeOfExpression = attribute.ArgumentList.Arguments[0].Expression as TypeOfExpressionSyntax;
                            if (typeOfExpression != null)
                            {
                                var typeSymbol = context.Compilation.GetTypeByMetadataName(typeOfExpression.Type.ToString());
                                return typeSymbol;
                            }
                        }
                    }
                }
                return null;
            }

            private string GenerateExtensionMethod(string namespaceName, string className, ITypeSymbol targetType, GeneratorExecutionContext context)
            {
                var targetTypeName = targetType.Name;
                var properties = targetType.GetMembers().OfType<IPropertySymbol>().Where(p => !p.IsStatic && p.DeclaredAccessibility == Accessibility.Public);

                StringBuilder source = new StringBuilder();
                source.AppendLine("using System.Collections.Generic;");
                source.AppendLine();

                if (!string.IsNullOrEmpty(namespaceName))
                {
                    source.AppendLine($"namespace {namespaceName}");
                    source.AppendLine("{");
                }

                source.AppendLine($" public static class {className}Extensions");
                source.AppendLine(" {");
                source.AppendLine($"  public static Dictionary<string, object?> ToDict<T>(this {className} ctx, T obj) where T : class");
                source.AppendLine("  {");
                source.AppendLine("   var dict = new Dictionary<string, object?>();");
                source.AppendLine($"   if (obj is not {targetTypeName} target)");
                source.AppendLine("   {");
                source.AppendLine("    return dict;");
                source.AppendLine("   }");

                foreach (var property in properties)

                    source.AppendLine($"   dict[\"{property.Name}\"] = target.{property.Name};");
                }

                source.AppendLine("   return dict;");
                source.AppendLine("  }");
                source.AppendLine(" }");

                if (!string.IsNullOrEmpty(namespaceName))
                {
                    source.AppendLine("}");
                }

                return source.ToString();
            }
    ```

### 示例：增量源生成器

以下是一个简单的增量源生成器的示例：

```csharp
using Microsoft.CodeAnalysis;
using Microsoft.CodeAnalysis.CSharp.Syntax;
using System.Collections.Immutable;
using System.Linq;

namespace Tsinswreng.SrcGen
{
    [Generator]
    public class MyIncrementalGenerator : IIncrementalGenerator
    {
        public void Initialize(IncrementalGeneratorInitializationContext context)
        {
            IncrementalValuesProvider<ClassDeclarationSyntax> classDeclarations = context.SyntaxProvider
                .CreateSyntaxProvider(
                    predicate: static (s, _) => IsSyntaxTargetForGeneration(s),
                    transform: static (ctx, _) => GetSemanticTargetForGeneration(ctx))
                .Where(static m => m is not null)!;

            IncrementalValueProvider<(Compilation, ImmutableArray<ClassDeclarationSyntax>)> compilationAndClasses
                = context.CompilationProvider.Combine(classDeclarations.Collect());

            context.RegisterSourceOutput(compilationAndClasses,
                static (spc, source) => Execute(source.Item1, source.Item2, spc));
        }

        static bool IsSyntaxTargetForGeneration(SyntaxNode node)
        {
            return node is ClassDeclarationSyntax m && m.AttributeLists.Count > 0;
        }

        static ClassDeclarationSyntax? GetSemanticTargetForGeneration(GeneratorSyntaxContext context)
        {
            var classDeclarationSyntax = (ClassDeclarationSyntax)context.Node;

            foreach (var attributeListSyntax in classDeclarationSyntax.AttributeLists)
            {
                foreach (var attributeSyntax in attributeListSyntax.Attributes)
                {
                    if (context.SemanticModel.GetSymbolInfo(attributeSyntax).Symbol is not IMethodSymbol attributeSymbol)
                    {
                        // malformed attribute.
                        continue;
                    }

                    INamedTypeSymbol attributeContainingTypeSymbol = attributeSymbol.ContainingType;
                    string fullName = attributeContainingTypeSymbol.ToDisplayString();

                    if (fullName == "MyAttribute") // 替换为你的 Attribute 名称
                    {
                        return classDeclarationSyntax;
                    }
                }
            }

            return null;
        }

        static void Execute(Compilation compilation, ImmutableArray<ClassDeclarationSyntax> classes, SourceProductionContext context)
        {
            if (classes.IsDefaultOrEmpty)
            {
                // nothing to do yet
                return;
            }

            foreach (var classDeclarationSyntax in classes)
            {
                string className = classDeclarationSyntax.Identifier.Text;
                string generatedCode = $@"
                namespace MyNamespace
                {{
                    public static class {className}Extensions
                    {{
                        public static string MyExtensionMethod(this {className} obj)
                        {{
                            return ""Hello from generated code!"";
                        }}
                    }}
                }}
                ";

                context.AddSource($"{className}Extensions.g.cs", generatedCode);
            }
        }
    }
}
```

确保你的源生成器项目正确实现了代码生成逻辑，并且在 `Ngan.Dict.Core` 项目中能够正确使用生成的代码。

```cs
using Microsoft.CodeAnalysis;
using Microsoft.CodeAnalysis.Text;
using System.Text;

namespace Tsinswreng.SrcGen
{
    [Generator]
    public class HelloGenerator : ISourceGenerator
    {
        public void Initialize(GeneratorInitializationContext context)
        {
            // 注册语法接收器以收集类声明
            context.RegisterForSyntaxNotifications(() => new SyntaxReceiver());
        }

        public void Execute(GeneratorExecutionContext context)
        {
            if (context.SyntaxReceiver is not SyntaxReceiver receiver)
                return;

            foreach (var classDecl in receiver.CandidateClasses)
            {
                var model = context.Compilation.GetSemanticModel(classDecl.SyntaxTree);
                var classSymbol = model.GetDeclaredSymbol(classDecl) as INamedTypeSymbol;

                // 检查类是否标记了[Hello]注解
                bool hasHelloAttribute = classSymbol.GetAttributes()
                    .Any(attr => attr.AttributeClass?.Name == "HelloAttribute");

                if (!hasHelloAttribute) continue;

                // 构建生成的代码
                string namespaceName = classSymbol.ContainingNamespace.ToDisplayString();
                string source = $@"
// <auto-generated/>
namespace {namespaceName}
{{
    public partial class {classSymbol.Name}
    {{
        public string Hello {{ get; set; }} = ""Hello World"";
    }}
}}";
                // 将代码添加到编译上下文
                context.AddSource($"{classSymbol.Name}.Hello.g.cs", SourceText.From(source, Encoding.UTF8));
            }
        }
    }

    // 语法接收器用于收集所有类声明
    internal class SyntaxReceiver : ISyntaxReceiver
    {
        public List<ClassDeclarationSyntax> CandidateClasses { get; } = new();

        public void OnVisitSyntaxNode(SyntaxNode syntaxNode)
        {
            if (syntaxNode is ClassDeclarationSyntax classDecl)
                CandidateClasses.Add(classDecl);
        }
    }
}
```

1.  **移除操作**

2.  **更新操作**

*   **基本概念**：`<None>` 元素用于表示项目中的一个项（item），该项不应被视为编译的输入。MSBuild 中的 Item 是一个命名的字符串引用，可以表示文件名等 [2](https://learn.microsoft.com/en-us/visualstudio/msbuild/common-msbuild-project-items?view=vs-2022)。
*   **使用场景**：
    *   **配置文件**：例如 `app.config` 或其他自定义配置文件。
    *   **静态内容**：例如 HTML、CSS、JavaScript 文件，这些文件在 Web 项目中可能需要被部署到服务器上。
    *   **脚本文件**：例如 PowerShell 脚本，用于执行构建或部署任务。
    *   **文档**：例如 `README.md` 或其他文档文件。
*   **常见属性**：
    *   `Include`：指定要包含的文件或文件模式。例如，`Include="*.txt"` 表示包含所有 `.txt` 文件。
    *   `Update`：类似于 `Include`，但用于更新已存在的项的属性 [3](https://medium.com/@codezone/managing-custom-files-with-none-update-and-none-include-in-msbuild-project-files-a-practical-6fac34980aba)。
    *   `CopyToOutputDirectory`：指定是否将文件复制到输出目录，以及何时复制。

        *   `PreserveNewest`：仅当源文件比目标文件新时才复制。

    *   `Pack`：指定在创建 NuGet 包时是否包含该文件。
    *   `PackagePath`：指定该文件在 NuGet 包中的路径。
*   **与 `<Compile>` 的区别**：
    *   `<Compile>` 用于指定需要被编译成代码的文件，例如 C# 文件 (`.cs`)。
    *   `<None>` 用于指定不需要被编译的文件，但可能需要在构建过程中进行处理或包含在输出中。


3.  **使用 `Any()` 方法检查是否为空**

    如果你仅仅需要知道 `IEnumerable<T>`  是否包含任何元素，而不需要具体的数量，可以使用 `Any()` 方法。  `Any()`  在找到第一个元素后就会停止遍历，因此在处理大型集合时，它可能比  `Count()`  更高效。

- 无法通过编译器的类型检查（泛型`T_Entity`的属性在编译期未知）
- EF Core无法解析动态属性名称到数据库列名

#### 2. 动态场景的特殊性
您的`DictCtx.Assign(Old, dict)`方法暗示存在反射或动态对象处理机制。但`ExecuteUpdate`的工作机制与内存对象操作存在本质差异：
- `ExecuteUpdate`直接在数据库层面生成UPDATE语句，不经过实体状态跟踪
- 动态属性赋值需要转换为可翻译的表达式树结构，这对泛型类型而言非常困难

---

### 三、解决方案与实施路径
#### 方案1：表达式树动态构建（高级技巧）
通过反射和表达式树动态生成`SetProperty`调用链，实现泛型支持。需注意EF Core 10对Lambda表达式的改进：
```csharp
var setters = dict.Aggregate(
    new List<Func<SetPropertyCalls<T_Entity>, SetPropertyCalls<T_Entity>>>(),
    (list, kv) => {
        var property = typeof(T_Entity).GetProperty(kv.Key);
        var parameter = Expression.Parameter(typeof(T_Entity));
        var propertyAccess = Expression.Property(parameter, property);
        var value = Expression.Constant(kv.Value);
        var setterExpr = Expression.Lambda<Func<SetPropertyCalls<T_Entity>, SetPropertyCalls<T_Entity>>>(
            Expression.Call(
                typeof(SetPropertyCalls<T_Entity>).GetMethod("SetProperty"),
                propertyAccess,
                value
            ), parameter);
        list.Add(setterExpr.Compile());
        return list;
    }
);

await DbSet.Where(e => ids.Contains(e.Id))
           .ExecuteUpdateAsync(setters.Aggregate(
               (current, next) => current.Then(next)
           ));
```

**注意事项**：
- 需要EF Core 10+支持标准Lambda表达式
- 必须确保字典键名与实体属性名完全匹配
- 复杂类型属性（如`I_PoBase`中的`UpdatedAt`）需特殊处理

#### 方案2：动态LINQ扩展（折中方案）
结合`System.Linq.Dynamic.Core`库实现动态属性访问：
```csharp
using System.Linq.Dynamic.Core;

var query = DbSet.Where("@0.Contains(Id)", ids);
foreach (var kv in dict) {
    query = query.SetProperty(kv.Key, kv.Value);
}
await query.ExecuteUpdateAsync();
```

**优势**：
- 避免手动构建表达式树
- 支持字符串形式的属性名

**限制**：
- 需引入第三方库
- 无法享受强类型检查

#### 方案3：分批次静态映射（保守方案）
若字段集合可预测，可为每个可能的字段创建条件分支：
```csharp
var query = DbSet.Where(e => ids.Contains(e.Id));

if (dict.ContainsKey("Field1"))
    query = query.SetProperty(e => e.Field1, dict["Field1"]);
if (dict.ContainsKey("Field2"))
    query = query.SetProperty(e => e.Field2, dict["Field2"]);

await query.ExecuteUpdateAsync();
```

**适用场景**：
- 字段集合相对固定
- 可接受一定程度硬编码

### 四、性能对比与选型建议

| 方案 | 性能 | 开发复杂度 | EF Core版本要求 | 动态性支持 |
|------|------|------------|----------------|------------|
| 表达式树 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 10+ | 完全动态 |
| 动态LINQ | ⭐⭐⭐ | ⭐⭐ | 7+ | 较高 |
| 分批次静态映射 | ⭐⭐ | ⭐ | 7+ | 低 |

**推荐路径**：
1. **优先尝试方案2**：在动态性与开发效率间取得平衡
2. **复杂场景使用方案1**：当字段变化频繁且需强类型保障时
3. **放弃ExecuteUpdate**：若上述方案均不适用，可退回到传统`SaveChangesAsync`模式，但需注意批量加载时的性能优化

### 五、补充优化建议
1. **字典预处理**：
```csharp
// 过滤无效字段名
var validDict = dict.Where(kv =>
    typeof(T_Entity).GetProperty(kv.Key) != null)
.ToDictionary(kv => kv.Key, kv => kv.Value);
```


2. **事务优化**：即使使用`ExecuteUpdate`，仍建议包裹在事务中以保证原子性
3. **并发控制**：添加`Where`条件实现乐观并发：
```csharp
.SetProperty(e => e.Version, e => e.Version + 1)
.Where(e => e.Version == originalVersion)
```

### 六、最终结论
在泛型实体+动态字段字典的场景下，**EF Core原生无法直接使用`ExecuteUpdateAsync`**，但可通过表达式树构建或动态LINQ扩展实现近似效果。建议根据字段动态程度和团队技术能力选择方案，若动态性要求极高，传统加载-修改-保存模式仍是可靠备选方案。
